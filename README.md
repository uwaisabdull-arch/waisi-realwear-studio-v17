# WAISI RealWear Studio V18

Production management workspace with one color × size matrix, customer pricing and printable production Tech Pack / quotation. No Design Studio, CAD, or AI API.

## Deploy to Render
Upload all files preserving the `public/index.html` folder. Build command: `npm install`; start command: `npm start`. Node 18+. The app stores data locally in the browser (localStorage), not in a cloud database. Use Export JSON regularly for backups.

## PDF
Open the Tech Pack or Quote tab and click PDF. In the browser print dialog select **Save as PDF**, enable background graphics if offered, and choose A4. Prices never appear in the Tech Pack.

## Notes
All dimensions, material claims and artwork details must be validated by the factory. Financial values are illustrative and editable. No tax/legal advice is implied.
